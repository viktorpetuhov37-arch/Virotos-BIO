# Как редактировать Virotos

Сайт работает на GitHub Pages без сборки и сторонних библиотек. Теперь каждый раздел отделён от остального кода.

| Что хочешь поменять | Какой файл открыть |
|---|---|
| Приветствие и четыре карточки | `index.html` |
| Цвета, фон, модальные окна | `css/main.css` |
| Содержимое раздела «Обо мне» и ссылки | `js/sections/about.js` |
| Стиль раздела «Обо мне» | `css/about.css` |
| Даты и события «Мой путь» | `js/data/journey.js` |
| Содержимое «Доски почёта» | `js/sections/honor.js` |
| Оформление «Доски почёта» | `css/honor.css` |
| Название, статус, адрес MP3 и текста | `js/data/tracks.js` |
| Внешний вид блока с плеером | `js/sections/music.js` и `css/music.css` |
| Логика плеера | `js/music/player.js` |
| Логика подсветки субтитров | `js/music/lyrics.js` |
| Текст песни и таймкоды | `music/kogda-idet-dozhd.lrc` |
| Открытие карточек, закрытие окон, копирование | `js/main.js` |

## Пример: изменить биографию
Открой `js/sections/about.js` на GitHub, нажми карандаш, поменяй нужный абзац и сделай Commit. Остальные файлы трогать не требуется.

## Пример: поправить субтитры
Открой `music/kogda-idet-dozhd.lrc` и измени секунды перед нужной строкой: `[00:21.70]` означает 21,70 секунды. Сохрани файл через Commit. Текст загружается при каждом открытии плеера.

## Как посмотреть изменения
Опубликованный сайт: https://virotos.ru . Локально для проверки запускай папку через локальный HTTP-сервер (например, `python -m http.server 8000`) и открывай `http://localhost:8000`. Из-за JS-модулей и загрузки LRC простое открытие файла `index.html` через `file://` может не работать.

## Как публиковать
Загружай в корень репозитория **содержимое** этого архива, а не внешнюю папку целиком. Файл `CNAME` с `virotos.ru` оставь. Никакие настройки DNS, Cloudflare и HTTPS менять не требуется. Перед заменой лучше сохранить отдельный коммит текущей рабочей версии.

Песня сейчас отмечена как неизданная, но если MP3 загружен в публичный репозиторий, его сможет получить любой посетитель по прямому адресу.
