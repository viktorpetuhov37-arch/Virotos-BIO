# VIROTOS BIO · 2026

Просто первый сайт.

## Как опубликовать

Загрузите содержимое папки в корень репозитория `Virotos-BIO` (включая `music/kogda-idet-dozhd.mp3`). Не удаляйте файл `CNAME` — он сохраняет `virotos.ru`.

Плеер использует HTML5 Audio и запускается пользователем. При закрытии окна музыка останавливается.

**Важно:** файл MP3 в публичном GitHub-репозитории / GitHub Pages открыт для скачивания по прямой ссылке, даже если трек обозначен как «неизданный». Не публикуйте его, если хотите сохранить запись приватной до релиза.

Разделы «Мой путь» и «Доска почёта» сохранены без изменений.
